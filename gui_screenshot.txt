Features:
- Checkboxes for default locations (Beaverton, OR, Portland, OR, Remote, Hawaii)
- Custom location input field with Add button
- Remove button for custom locations
- Status showing number of selected locations
- Save/Cancel buttons
- Error messages for validation
- Hawaii is prominently featured as a recommended location

The GUI is implemented using egui and provides a clean, intuitive interface
for location configuration. It automatically shows when the configuration 
is incomplete (Hawaii missing) and saves the results to AgentConfig.toml.
